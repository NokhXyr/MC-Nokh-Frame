# Nokh Frame 0.5.5

Minecraft **1.21.1** · NeoForge **21.1.1 or newer (21.1.x)** · Client-side

## English

Nokh Frame 0.5.5 lowers the minimum NeoForge version from 21.1.250 to 21.1.1. The JAR is compiled against 21.1.1. The seven GameTests passed on both 21.1.1 and 21.1.252; an automated client test opened and rendered the studio on both versions. Intermediate NeoForge builds have not each been tested.

Install `nokhframe-0.5.5.jar` in your Minecraft 1.21.1 instance's `mods` folder. Join a world and enter `/nokhframe` in chat. See the [English guide](https://github.com/NokhXyr/Nokh-Frame/blob/main/docs/USER_GUIDE.en.md) and [changelog](https://github.com/NokhXyr/Nokh-Frame/blob/main/CHANGELOG.md).

## Français

Nokh Frame 0.5.5 abaisse la version minimale de NeoForge de 21.1.250 à 21.1.1. Le JAR est compilé avec 21.1.1. Les sept GameTests réussissent sur 21.1.1 et 21.1.252 ; un test client automatisé ouvre et rend le studio sur ces deux versions. Les versions intermédiaires de NeoForge n'ont pas été testées individuellement.

Placez `nokhframe-0.5.5.jar` dans le dossier `mods` de votre instance Minecraft 1.21.1. Entrez dans un monde et saisissez `/nokhframe` dans le chat. Consultez le [guide français](https://github.com/NokhXyr/Nokh-Frame/blob/main/docs/USER_GUIDE.fr.md) et le [journal des versions](https://github.com/NokhXyr/Nokh-Frame/blob/main/CHANGELOG.fr.md).
