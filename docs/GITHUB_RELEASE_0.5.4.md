# Nokh Frame 0.5.4

Minecraft **1.21.1** · NeoForge **21.1.250 minimum** · Client-side / Côté client

## English

Nokh Frame 0.5.4 adds a PNG background library for player and item photos. Import an image by dragging it into the library or entering its path; choose it from the list and capture your preview. Backgrounds may be up to 4096 × 4096 pixels and 16 MB.

This release also moves Walk, Run and Sneak limb posing to the player model render step. In the dedicated client test world, the walking pose was visible in the captured preview. Seven headless NeoForge GameTests passed.

**Install:** Place `nokhframe-0.5.4.jar` in the `mods` folder of a Minecraft 1.21.1 instance with NeoForge 21.1.250 or newer in the 21.1.x line. Join a world, then type `/nokhframe` in chat. The JAR is for the client. Read the [English user guide](https://github.com/NokhXyr/Nokh-Frame/blob/main/docs/USER_GUIDE.en.md) and [full changelog](https://github.com/NokhXyr/Nokh-Frame/blob/main/CHANGELOG.md).

## Français

Nokh Frame 0.5.4 ajoute une bibliothèque de fonds PNG pour les photos du joueur et des items. Importez une image par glisser-déposer ou en saisissant son chemin, choisissez-la dans la liste et prenez la photo. Un fond peut mesurer jusqu'à 4096 × 4096 pixels et 16 Mo.

Cette version applique aussi la pose des membres pour la marche, la course et l'accroupissement au moment du rendu du modèle joueur. La pose de marche est visible dans la capture produite dans le monde de test dédié. Les sept GameTests NeoForge sans interface réussissent.

**Installation :** placez `nokhframe-0.5.4.jar` dans `mods` pour une instance Minecraft 1.21.1 avec NeoForge 21.1.250 minimum (branche 21.1.x). Entrez dans un monde puis saisissez `/nokhframe` dans le chat. Le JAR s'installe côté client. Consultez le [guide français](https://github.com/NokhXyr/Nokh-Frame/blob/main/docs/USER_GUIDE.fr.md) et le [journal complet](https://github.com/NokhXyr/Nokh-Frame/blob/main/CHANGELOG.fr.md).
